# AI 助手多轮对话与追问功能

## Goal

为 AI 助手模式添加多轮对话能力，让用户可以基于之前的回复继续追问，实现连续的语音交互体验。

## Background

当前 AI 助手模式是严格的单轮对话：
- 每次交互独立，无上下文记忆
- 结果面板只显示单条结果
- LLM 调用只发送 `[system, user]` 消息对
- 用户完成一次交互后只能复制或关闭

## Current Implementation Analysis

### 后端
- `assistant_processor.rs`: 无状态处理器，每次调用都是全新的 `[system, user]` 消息
- `pipeline/assistant.rs`: 无状态编排器，不跟踪会话
- `PendingAssistantResult`: 仅存储单条结果 (`Option<PendingAssistantResult>`)，新结果会驱逐旧结果
- `openai_client.rs`: `chat_simple()` 方法支持 `Vec<ChatMessage>`，理论上**已支持多轮**

### 前端
- `ResultPanelWindow.tsx`: 单结果展示 (push+pull 双模式)，无对话历史
- 操作只有：复制、关闭、粘贴
- 窗口配置：520×620, transparent, resizable, always-on-top, focusable
- Markdown 渲染：MarkdownRenderer.tsx (GFM + 语法高亮)

### 关键约束
- 交互方式是语音 + 快捷键，不是键盘打字
- 结果面板是独立 Tauri 窗口
- 需要兼容两种场景：Q&A 模式和文本处理模式

## Requirements

### R1: 面板状态即对话状态

核心规则：**面板开 = 追问，面板关 = 新对话**

| 用户操作 | 面板状态 | 行为 |
|---------|---------|------|
| 按助手热键 | 面板**关闭** | 开始**新对话** |
| 按助手热键 | 面板**打开** | 进入**追问模式**（自动携带对话上下文） |
| 关闭面板 (✕ / Esc) | 打开→关闭 | 结束当前对话会话，历史写入 History |

不需要「新对话」按钮。想开新对话，关面板即可。

### R2: 追问同时支持纯语音和携带新选中文本

- **纯语音追问**：面板打开 → 不选任何文本 → 按热键录音 → 追问
- **带新上下文追问**：面板打开 → 在其他窗口或面板内选中文本 → 按热键录音 → 携带新选中文本追问

### R3: 面板从单结果卡片升级为对话流视图

- 每轮显示：用户语音指令 + 附带的选中文本(如有) + AI 回复 + 耗时
- 轮次之间有视觉分隔
- 支持 Markdown 渲染（复用 MarkdownRenderer）
- 操作栏：复制最新回复 / 复制全部对话

### R4: 滚动行为符合逻辑

| 场景 | 滚动行为 |
|------|---------|
| AI 新回复到达 | 自动滚到底部 |
| 用户手动向上滚动 | 保持位置不动 |
| 用户已上滚 + 新回复到达 | 不抢滚动，显示「↓ 查看最新回复」浮标 |
| 用户点击浮标 | 平滑滚到底部 |
| 追问录音中 | 面板保持可见且位置不变 |

### R5: 追问时面板保持可见

- 面板不隐藏，用户可参考之前的回复内容
- Overlay 录音指示器照常出现
- 面板位置和尺寸不变（只有首轮才居中定位）

### R6: 多轮消息构建

- system_prompt_mode 由首轮锁定（有选中文本 → TextProcessing，无 → QA）
- 追问不改变 system prompt
- 追问时的新选中文本作为 user message 附件
- LLM messages 数组：`[system, user₁, assistant₁, user₂, assistant₂, ..., userₙ]`

### R7: 对话轮次上限

- 最多 20 轮（发送 LLM 时截断最早轮次，保留 system prompt + 最近 N 轮）
- 前端显示完整历史，不截断

### R8: 处理中阻止重复触发

- LLM 调用期间，助手热键不响应
- "AI 思考中..." 状态本身作为视觉反馈

### R9: 错误处理

- LLM 调用失败时在对话流中显示错误气泡
- 不中断会话，不写入 session.turns
- 用户可直接重试（再按热键，仍为追问模式）

### R10: 单轮兼容

- 只有 1 轮的会话 = 当前体验的超集，无功能退化

## Acceptance Criteria

- [ ] 面板关闭时按助手热键 → 新对话，面板显示首轮结果
- [ ] 面板打开时按助手热键 → 追问，面板追加新轮次
- [ ] 追问时不选文本 → 纯语音追问，LLM 收到完整对话历史
- [ ] 追问时选中其他窗口文本 → 文本作为新上下文附件
- [ ] 追问时选中面板内 AI 回复文本 → 同样作为新上下文附件
- [ ] 关闭面板 → 会话结束，完整对话写入 History
- [ ] 新回复到达 → 自动滚到底部（用户在底部时）
- [ ] 用户上滚后新回复到达 → 不抢滚动 + 出现浮标
- [ ] 点击浮标 → 平滑滚到底部
- [ ] 追问录音中面板保持可见、位置不动
- [ ] LLM 处理中再按热键 → 无响应
- [ ] LLM 失败 → 错误气泡，可重试
- [ ] 超过 20 轮 → LLM 只收最近 20 轮，前端显示完整历史
- [ ] 单轮使用（不追问直接关闭）→ 体验与当前版本一致

## Definition of Done

- 所有 Acceptance Criteria 通过
- 单元测试覆盖：多轮消息构建、滑动窗口截断、PromptMode 锁定、对话格式化、滚动状态计算
- 手动测试覆盖：新对话→追问→关闭 全流程、纯语音/带文本追问、错误重试、快速连按

## Out of Scope

- 流式响应（Streaming）— 当前 LLM 调用为完整返回，不在本次改造
- 对话持久化/跨会话恢复 — 关闭面板即会话结束，不保存对话供日后恢复
- 对话分支/编辑历史消息 — 不支持修改已发送的消息
- 键盘文字输入追问 — 仅支持语音交互，不添加文本输入框
