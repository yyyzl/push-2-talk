# Phase 7 Current State Audit

## Code Coverage Observed

- `src-tauri/src/personalization/hotword_compiler.rs`
  - Defines `AsrHotwordPack`, `AsrHotword`, `TnlDictionaryPack`, `LlmContextPack`, and `CorrectionHint`.
  - Compiles user dictionary metadata, correction pairs, recent entries, app-context entries, domain entries, and builtin entries.
  - Sorts by source priority: manual user > correction pair > recent > app context > automatic user > domain > builtin.
  - De-duplicates pure words and truncates by provider max count.
  - Keeps Doubao render output as legacy `{"word": "<pure word>"}` objects.

- Provider integration
  - `src-tauri/src/asr/http/qwen.rs` uses `compile_asr_pack_with_correction_pairs` and `render_qwen_corpus_text`.
  - `src-tauri/src/asr/realtime/qwen.rs` uses the same compiler for realtime corpus text.
  - `src-tauri/src/asr/http/doubao.rs` uses the compiler and `render_doubao_hotwords`.
  - `src-tauri/src/asr/realtime/doubao.rs` uses the compiler and `render_doubao_hotwords`.

- Runtime dictionary inputs
  - Frontend recent hotwords are generated by `src/utils/recentHotwords.ts`.
  - `src/hooks/useAppServiceController.ts` merges recent hotwords into runtime dictionaries without persisting them as user dictionary entries.
  - Backend app-context hotwords are generated by `src-tauri/src/personalization/app_context_hotwords.rs` and appended to current recording snapshots in `src-tauri/src/lib.rs`.

## Intentional Differences From Original Phase 7 Text

- The original plan mentions Doubao weighted JSON. Current executable spec requires legacy-compatible `{"word": ...}` without `weight` until provider compatibility is verified.
- The original plan mentions cache reuse when dictionary and app context do not change. Current implementation compiles from snapshots at provider request/session construction time; cache optimization remains optional because compile cost is bounded and already covered by provider limits.

## Remaining Work

- Consider a small compile-cache only if profiling shows HotwordCompiler cost matters.
- Revisit provider-specific weighted Doubao payloads only after compatibility is verified against real API behavior.
