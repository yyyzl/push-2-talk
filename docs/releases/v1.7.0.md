# Windows 与 macOS 整合版

这次更新把 Windows 的现有功能与 macOS 原生适配整合到同一条版本线。听写、AI 助手、识别模型、词库与配置使用共同的处理逻辑；快捷键、窗口焦点和文本回填分别由两端的原生实现负责。

## 主要变化

- **macOS 首次随正式版本提供安装包**：提供 Apple Silicon DMG，加入麦克风、辅助功能、输入监控的权限引导，以及适合 macOS 的按键名称、窗口工具栏和图标。
- **保留 Windows 旧版配置**：已有的识别引擎、API Key、LLM 提供商、快捷键和模型选择继续沿用；修复初始化尚未完成就自动保存配置的问题，避免新默认值覆盖旧设置。
- **千问模型选择更清楚**：支持 Audio 3.1、Audio 3.0 和旧版 Qwen3，区分 HTTP 与实时模型，并保留用户的显式选择。
- **词库与纠词管理改进**：个人词库使用 SQLite 持久化，普通设置保存不会覆盖已初始化的词库；改进纠词关系、热词来源和学习任务的隔离。
- **助手与输入稳定性改进**：完善选区捕获、目标窗口和浏览器标签恢复、目标关闭后的防误写；macOS 临时粘贴保留富文本和图片剪贴板内容，并优先保留用户后来复制的内容。
- **模型与交互改进**：助手支持配置联网搜索、按模型选择思考选项，统一选择器交互并明确配置保存状态。
- **修复启动与打包问题**：应用状态在窗口创建前注册，修复 Windows 启动竞态；对齐 Tauri 打包工具链，保留 NSIS 升级方式。

## Windows 用户如何升级

完全退出 PushToTalk 后，使用新安装器覆盖原安装即可，无需先卸载或清空配置。应用内更新也使用同一套 NSIS 安装包。

升级前如需备份，请同时保留 `%APPDATA%\PushToTalk\` 和 `%LOCALAPPDATA%\com.pushtotalk.app\`：前者包含配置、个人词库等，后者包含历史记录使用的 WebView 本地存储。仅复制 `config.json` 并不是完整备份。已有历史仍按最近 50 条保留；若切换后暂时为空，先完全退出并重开，仍异常时保留数据目录并反馈。

## macOS 安装与授权

打开对应架构的 DMG，将 PushToTalk 拖入“应用程序”后启动。首次使用需要允许麦克风、辅助功能和输入监控，然后回到应用刷新权限状态并启动服务。

**本次 macOS 包采用 ad-hoc 签名，未获得 Apple Developer ID 签名与公证。** 首次打开可能被系统拦截；确认来源后可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在“系统设置 → 隐私与安全性”中处理该应用的打开许可。安装或升级后可能需要重新授权；若开关已开但应用仍报告未授权，移除旧权限条目，再添加“应用程序”中的当前版本，并按系统提示重开。

更新包使用的 Tauri 签名不等同于 Apple 公证。本次不承诺 macOS 升级后无需再次授权。

## 验证范围与已知限制

- Windows 与 macOS 均执行原生 CI 编译、自动测试和打包检查；发布流程还验证两套产物齐全、更新签名与应用公钥匹配。
- Windows 已验证 v1.6.1 的配置迁移、覆盖升级以及连续启动场景。物理麦克风、全局快捷键到各类目标应用的完整矩阵，以及最终公开渠道的自动更新安装，仍不能用 CI 构建结果代替。
- macOS 已有 TextEdit、Chrome、Safari 等场景的听写、助手、目标保护与词库学习实测；全屏悬浮窗、多屏、设备切换和不同应用的文本读取兼容性仍有未覆盖项。
- “录音时静音其他应用”目前仅 Windows 支持。macOS 对应选项不可用，Fn / Globe 暂不作为独立快捷键绑定。
- 第三方 ASR、LLM 和搜索服务的配额、计费及可用性取决于所选服务。
