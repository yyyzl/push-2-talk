## 已落实的集成决策

1. **原生能力经 `platform` 调用。** 共享业务层不依赖 Win32/UIA。新增 `DesktopBackend::read_selection(InputTarget)`，Windows 使用 UIA，Mac 使用 AX 的选区属性。保留平台各自的原生实现。
2. **选区必须属于捕获的目标。** 读取前后核对焦点。Mac 对密码框、过期目标、读取中切换焦点返回失败；选区不可用时不把完整文本当选区。剪贴板回退保留目标恢复失败即停止的约束。
3. **SQLite 是用户词典的主存储。** 配置加载读取数据库，不反向覆盖数据库。只有全新数据库才从 JSON 快照初始化；禁用最后一个词后，旧快照和运行时输入不能把它重新带回来。近期词等临时来源继续保留。
4. **纠错文件统一使用平台原子替换。** 唯一临时文件、落盘、关闭、原子发布；串行保护整个读改写过程，避免学习任务与 LLM 反馈丢失彼此更新。失败不得移动或覆盖原来的目录。
5. **构建使用各平台原生工具。** 移除全局指向 Windows `.cmd` 的 CMake 设置，保留旧版 Opus 的 CMake 兼容策略。锁文件只补新增依赖，保留已验证的 Tauri 版本。
6. **保留已接受的产品与项目约定。** 保留两平台新图标、Mac 标题栏与权限页，也保留 Windows 新功能。沿用 Windows 分支对旧工具流程的清理；项目工具凭据改从环境变量读取。

## 本地验证

在 macOS 原生工具链执行，不使用真实用户配置或外部 ASR/LLM 服务：

- `npm ci`、`npm run test:ts`：152 项通过。
- `npm run build`：通过。
- 浏览器预览可渲染主页、权限区、口语流畅化和助手搜索设置；没有 Tauri IPC 的浏览器会显示原生命令不可用，因此这仅是渲染检查，不算桌面功能验收。
- `cargo test --locked --manifest-path src-tauri/Cargo.toml`：543 项通过，7 项忽略（含 2 项文档示例）。
- `cargo check --locked --features atdd --manifest-path src-tauri/Cargo.toml`：通过。
- `sh scripts/test-macos-hotkey-native.sh`：通过，新增选区读取的目标、密码框和焦点变化场景。

新修复先验证失败再实现：目录目标被移动、并发纠错丢失更新、删除词条被旧快照恢复、Mac 原生选区读取。学习 HTTP 测试使用本地模拟服务，已改为复用真实生产模块，避免复制模块造成依赖漂移。

Windows 本地编译、原生输入与桌面验收不能由这些 Mac 测试代替。双平台 CI 负责各自的编译、测试及原型打包，实机验收另行记录。

集成代码提交 `8600483` 的双平台构建记录见 [Platform checks #36343536402](https://github.com/yyyzl/push-2-talk/actions/runs/36343536402)。后续仅更新文档的提交不改变这份被测代码。

## 合入 main 前的验收门槛

| 优先级 | 项目 | 当前结论与下一步 |
| --- | --- | --- |
| P1 | 录音启动、快速松键、停止服务竞态 | 新增选区/上下文读取在异步启动前等待；代码审查发现启动任务缺少生产环境生命周期约束。需要延迟注入测试，验证停止后不会晚到启动或留下旧选区；必要时将准备、录音和停止纳入同一会话生命周期。尚未声称已复现实机故障。 |
| P1 | 新功能双平台端到端验收 | 助手选区与搜索、ASR 模型切换、个性化学习、词条新增/删除/重启，需在隔离配置上分别验收，避免把用户正式配置作为迁移实验。 |
| P1 | Windows 输入回归 | UIA 读取、剪贴板回退、窗口/控件切换、快捷键看门狗和音频静音须在 Windows 桌面验证。CI 编译成功不等于这些交互通过。 |
| P2 | SQLite 与 JSON 快照错误语义 | 数据库提交后，JSON 快照保存失败仍可能让命令报错；需要明确已提交状态与重试行为。两者并非跨存储事务，不能承诺同步原子性。 |
| P2 | 真实服务协议验收 | 搜索提供方、Qwen 新模型配置、推理参数需用受控真实请求验证；当前 HTTP 模拟测试不代表全部服务线上兼容。 |

完成以上门槛后再评估向 `main` 提交合并请求。不得把历史 Mac 单独分支的实机通过结果自动视为本集成版本已通过。
